# 波形检测
## 大致流程
```mermaid
graph TD
    B(ADC采样输入) --> D["BRAM<br/>以后考虑改成循环缓冲"]
    D --> E[分析RAM中的数据]
    E --> F{计算的斜率}
    F --> G{统计斜率特征: <br> - 平坦点计数<br> - 陡峭点计数<br> - 等效斜率值等}
    G --> H{波形分类逻辑}
    H -- 斜率大部分平坦, 少数极陡 --> I[判断为方波]
    H -- 斜率交替出现恒定正/负值 --> J[判断为三角波/锯齿波]
    H -- 其他情况,且THD很小 --> K[判断为正弦波]
    I --> L[输出波形类型]
    J --> L
    K --> L
    L --> N[结束/等待下次采样]
```
## 交互协议

1.  **复位**: 将 `reset` 信号置为高电平至少一个时钟周期以初始化模块。
2.  **启动**: 在 `start_analysis` 端口上发送一个单周期的启动脉冲, 命令模块开始新一轮的波形分类。
3.  **读取结果**: 当 `done` 信号为高电平时, 在该时钟周期从 `waveform_type` 端口上读取有效的分类结果。
